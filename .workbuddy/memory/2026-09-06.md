# 2026-09-06 Agnes AI Playground v2.0 全面升级 + Bug修复

## 本次 Bug 修复（v2.0.1）

### Bug 1: 文生图请求失败 - URL 双拼接
**错误**: `Invalid URL (POST /v1/v1/images/generations)`
**原因**: `generateImage()` 中 `url` 变量已含 `/v1`，fetch 又拼 `/v1/images/generations` → 双重 `/v1`
**修复**: 
- 第 1179 行：统一用 `url = url.replace(/\/v1\/?$/, '') + '/v1'` 规范化
- 第 1197 行：fetch URL 改为 `` `${url}/images/generations` ``（去掉多余的 `/v1`）

**备份**:
- `agnes-playground-v2-backup-20260906-002319.html`（修复前）
- `agnes-playground-v2-backup-20260906-003338.html`（修复后）

### Bug 2: 视频轮询 `checkModel()` 读 DOM 失败
**错误**: 异步轮询中 `checkModel()` 读不到当前选中的模型
**原因**: 内联函数在闭包中读取 DOM，时机问题导致返回 null
**修复**: 改为在调用处直接传入 `model` 参数，移除内联检查函数

### Bug 3: 图生视频 mode 写死为 text
**错误**: 有图片输入时仍用 `mode: 'text'` 而非 `mode: 'reference'`
**修复**: `generateImg2Vid` Flash 分支改为 `mode: 'reference'`，`extra_body: { images: [...] }`

### Bug 5: 文生图 negative_prompt 不支持
**错误**: `negative_prompt is not supported by text image queue`
**原因**: Agnes 图片生成 API 不支持 negative_prompt 参数
**修复**: 移除 `generateImage()` 和 `generateImg2Img()` 中的 `negative_prompt` 赋值
